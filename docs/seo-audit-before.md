# SEO audit before changes

Baseline recorded from route metadata, rendered source and local SSR checks on 2026-10-30, before the SEO metadata changes. React Router 7.18.3, SSR enabled and English prerender output. The site URL was unset: all canonical URLs and og:url tags were absent. No page had a robots meta directive. The robots file blocked /cart, /checkout and /wishlist.

52 intended public content pages plus three user-state pages are listed below. Every page had one H1; animation copies are aria-hidden. All pages emitted Organization and ClothingStore; /faq additionally emitted FAQPage. Product/Offer, WebSite and BreadcrumbList were absent. Arabic used cookie-only language selection on the same URLs and repeated one generic meta description on every page.
